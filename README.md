A tiny program for the [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — the funniest deadpan
one-star review, 160 characters or fewer, of an everyday essential:

> One star. Sleep promised eight hours of rest and delivered a 3 a.m. rerun of every embarrassing thing I've said since 2009.

A complaint filed in earnest against a thing that cannot be fixed,
with the sting turning in the last few words.

## Run it

```sh
python3 main.py
```
